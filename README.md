# Learning C

Exercícios iniciais de programação em C — calculadoras em linha de comando.

## Arquivos

| Arquivo | Descrição |
|---|---|
| `Calculadora_1.c` | Primeira versão da calculadora |
| `Calculadora_2.c` | Segunda versão, com melhorias |

## Como executar

Com GCC (Linux, macOS ou MinGW no Windows):

```bash
gcc Calculadora_1.c -o calculadora1
./calculadora1
```

```bash
gcc Calculadora_2.c -o calculadora2
./calculadora2
```
